# Define verdict, comparison, and Skeptic Review semantics

## Question

What deterministic rules and bounded model roles produce `REJECT`, `CONDITIONAL`, and `STRONG FIT`, separate Evidence Coverage from Mission fit, compare survivors without opaque scoring, expose counterfactuals, and prevent correlated sources or failed requirements from appearing supportive? Prove the semantics on positive, veto, missing-authority, contradictory, stale, and model-misrouting cases.
