# Primary-source audit: Mireye Site Expedition dependencies

**Retrieval date:** 2026-08-15  
**Scope:** Google Maps Platform/Aerial View/Photorealistic 3D Tiles and GCP controls; Google Earth Engine quotas, licensing, and dataset limits; AWS Open Data; direct US public data; relevant repository evidence.  
**Method:** Read-only inspection of public first-party documentation and repository artifacts. No authenticated or metered call was made, no service was enabled, and no configuration was changed.

## Status key

- **PROVEN** — supported by an official source and matching repository evidence.
- **DOCUMENTED** — officially supported, but not demonstrated in this repository.
- **PARTIAL** — a call or artifact exists, but coverage, calibration, authority, or operational behavior is incomplete.
- **BLOCKED** — configuration, license, authority, or another dependency prevents an honest MVP claim.
- **NOT AUTHORITY** — useful context or proxy, but cannot establish the decision fact.

## Executive finding

The evidence stack is feasible for a challenge prototype if it remains a screening and diligence-orchestration product. It is not feasible as a nationally authoritative source of availability, zoning, water rights, truck ingress, or utility capacity.

Four corrections are required before implementation:

1. **Remove FABDEM from any commercial-capable default path.** The current 3D/height witness loads the community Earth Engine asset `projects/sat-io/open-datasets/FABDEM` ([repo](../iteration-7/serve.py#L98-L145)). The authoritative University of Bristol record says FABDEM V1-2 is **CC BY-NC-SA 4.0** and directs commercial-use requests to the provider ([record API](https://data.bris.ac.uk/data/api/3/action/package_show?id=s5hqmjcdj8yo2ibzi9b4ew3sn)). It is usable only for a clearly noncommercial challenge demonstration unless permission is obtained. Use public-domain USGS 3DEP as the MVP terrain source and treat a second DEM as an optional, separately cleared witness.
2. **Do not ship the saved Aerial View playback URI.** Google permits indefinite storage of the `videoId`, but generally prohibits storage/caching of Aerial View content ([policy](https://developers.google.com/maps/documentation/aerial-view/policies), [overview](https://developers.google.com/maps/documentation/aerial-view/overview)). The repository HTML persists both a `videoId` and an expiring signed playback URL ([artifact](../uchicago-aerial-view.html#L9-L18)). Retain only the ID and perform a runtime `lookupVideo`; do not download video bytes.
3. **Keep Google pixels out of scoring and geometry.** Map Tiles is visualization-only; policy forbids image analysis, machine interpretation, object detection/identification, geodata extraction/resale, and offline use ([policy](https://developers.google.com/maps/documentation/tile/policies)). The current Iteration 7 design correctly keeps Google tiles out of evidence and enables on-screen Cesium credits ([server](../iteration-7/serve.py#L1-L6), [client](../iteration-7/app.js#L66-L70)). Preserve that boundary.
4. **Re-baseline Earth Engine cost controls.** Since 27 April 2026, noncommercial projects are moving to monthly EECU tiers: Community 150 EECU-hours, Contributor 1,000 (billing account required but no EE charge while noncommercial), and Partner 100,000 after review. Exhaustion causes restricted mode rather than a hard stop, and annual reverification is required ([tiers](https://developers.google.com/earth-engine/guides/noncommercial_tiers)). The prototype must inspect its project tier/usage before any live demo and must not assume legacy unlimited behavior.

### Repository policy observations

- The tile proxy reads the key server-side and returns `Cache-Control: no-store` ([server](../iteration-7/serve.py#L165-L214)); this is a reasonable prototype pattern, although production keys still need verified restrictions.
- The UI uses `showCreditsOnScreen: true` ([client](../iteration-7/app.js#L66-L70)), matching Google’s Cesium attribution guidance.
- The current local Aerial View HTML stores an expiring signed playback URL. Because only the ID is expressly exempt from caching restrictions, do not distribute or reuse this artifact; replace it with runtime lookup.
- A Google tiles HTTP 200 proves configured access, not stable browser performance, universal coverage, export rights, or analytical authority.

## AWS Open Data

**Finding: useful distribution layer, not a new authority.** AWS says its sponsorship covers storage and sharing of selected public datasets, while users generally pay for the compute they use ([program](https://aws.amazon.com/opendata/)). The Registry warns that datasets usually are maintained by third parties under varying licenses, so each entry must be checked ([registry FAQ](https://registry.opendata.aws/faq/)). “On AWS” therefore creates neither a new evidence source nor blanket commercial permission.

| Candidate | Official evidence | MVP implication |
|---|---|---|
| NOAA NEXRAD | Near-real-time and archive radar; public NOAA terms; no-sign-request S3 access ([registry](https://registry.opendata.aws/noaa-nexrad/)). | **DOCUMENTED, nonredundant for a selected event witness**, but substantial radar processing/calibration. Stretch only; not a general flood determination. |
| NOAA HRRR | Hourly 3 km atmospheric model, archive since 2014; public NOAA terms; no-sign-request access ([registry](https://registry.opendata.aws/noaa-hrrr-pds/)). | **DOCUMENTED.** Useful for operational/event weather context, not site climatology or future climate. Processing and model interpretation exceed MVP need. |
| USGS 3DEP lidar | Public-domain point clouds. Public EPT bucket covers most resources; raw LAZ bucket is more complete but Requester Pays and may contain missing/incomplete CRS metadata ([registry](https://registry.opendata.aws/usgs-lidar/)). | **Best AWS-adjacent stretch.** It can arbitrate elevation on selected finalists, but coverage/CRS/processing must be checked. Requester Pays means data transfer charges are possible. |
| USGS Landsat | Daily additions, unrestricted reuse with requested source statement, but the S3 collection is Requester Pays ([registry](https://registry.opendata.aws/usgs-landsat/)). | **Redundant for MVP** with the same Landsat source already in Earth Engine. Do not count it as independent evidence or add an AWS pipeline for theater. |

No AWS resource was called and no AWS credit/configuration was inspected. The exact MVP should have **no AWS dependency**. Add one dataset only after a named skill demonstrates information gain that Mireye, Earth Engine, or the source agency’s direct API cannot provide more simply.

## Independence and authority rules

1. Record the underlying dataset/provider, not merely the access platform. `Mireye → JRC`, `Earth Engine → JRC`, and `AWS/other mirror → JRC` are one independence group.
2. A direct official call adds authority/freshness only if it retrieves a more current or more granular official record. Re-querying the identical NFHL/CDL/3DEP value is a cross-check, not independent corroboration.
3. Google imagery and tiles are presentation-only; AWS is generally distribution; Earth Engine is computation plus catalog access. None automatically upgrades a value to legal/engineering authority.
4. Missing, timed-out, stale, preliminary, contradictory, license-unclear, or geometry-mismatched evidence must yield `CONDITIONAL`, never a pass.

## Exact MVP implications

- **Keep:** Mireye present-state screening; selective EE JRC history, CDL/CHIRPS, MODIS LST, and carefully labeled CMIP6 ensemble work; FEMA/USGS/EPA/EIA/Census/FHWA direct connectors only when they add authority or a missing fact; live Google 3D/Aerial visuals outside scoring.
- **Replace:** FABDEM in the default height witness with USGS 3DEP or another commercially cleared second DEM; the saved Aerial playback URL with runtime ID lookup.
- **Defer:** AWS processing pipelines, NEXRAD/HRRR event modeling, commercial EE switching, Aerial render requests for missing sites, and Routes enablement until a separately approved cost/configuration test.
- **Never claim from this stack:** listing availability, parcel identity without resolution, permitted use, water rights/yield, deliverable electrical MW, enterprise-fiber redundancy, truck ingress, building condition, legal wetland boundary, survey-grade elevation, or permit-ready concept fit.
- **Pre-demo gate:** verify EE registration/tier/remaining usage, Google API restrictions and per-service quotas, actual Aerial/3D coverage for the chosen addresses, attribution visibility, and that no signed Google content URL or API key is embedded in distributable artifacts.

## Overall verdict

**GO for a bounded, conditional challenge MVP after the two artifact/license corrections above. NO-GO for any authoritative or commercialized claim set until FABDEM is removed or licensed, Google content handling is cleaned up, Routes is explicitly enabled/tested, and state/local/utility verification adapters are scoped.**
